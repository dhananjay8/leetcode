# DSA Study Hub

Use this folder as your quick-launch area for coding interview prep.

## Start here
1. Read `cheat-sheet.md` (pattern triggers + templates)
2. Review `sorting-algorithms.md`
3. Use `pattern-identification.md` for 60-second pattern selection
4. Use `pattern-links.md` for curated external references
5. Use legacy notes if needed: `DSA - NOTES.txt`, `DSA - Patterns.txt`

## Suggested daily loop (60–90 mins)
- 10 min: Review one pattern from `cheat-sheet.md`
- 35 min: Solve one medium problem
- 20 min: Re-solve one past mistake without looking at solution
- 10 min: Update your mistake log (root cause + fix)

## Pattern-first progression
- Week 1: Arrays/Hashing, Two Pointers
- Week 2: Sliding Window, Prefix Sum, Binary Search
- Week 3: Stack/Queue, Intervals, Monotonic Stack
- Week 4: Linked Lists
- Week 5: Trees (DFS/BFS/BST)
- Week 6: Graphs, Union-Find, Topological Sort
- Week 7: Heap, Greedy, Backtracking
- Week 8+: Dynamic Programming and mixed mock sets

## Interview readiness checklist
- Can identify pattern in < 60 seconds
- Can explain brute force then optimize
- Can reason about edge cases and constraints
- Can articulate time/space complexity clearly
