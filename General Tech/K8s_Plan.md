∟ 📂 Phase 1 (Weeks 1–4) Foundations
 ∟ 📂 Linux basics for Kubernetes processes, and networking
 ∟ 📂 Git and GitHub for storing manifests and workflows
 ∟ 📂 Networking basics IP, DNS, HTTP, and load balancers

∟ 📂 Phase 2 (Weeks 5–8) Containers First
 ∟ 📂 Docker fundamentals images, containers, and layers
 ∟ 📂 Dockerfile build, tag, and push cycles
 ∟ 📂 Container networking including ports and health checks
 ∟ 📂 Registry setup such as ECR, ACR, GCR, Docker Hub
 ∟ 📂 Run multi container apps with docker compose

∟ 📂 Phase 3 (Weeks 9–12) Kubernetes Fundamentals
 ∟ 📂 Core objects Pods, Deployments, and ReplicaSets
 ∟ 📂 Services ClusterIP, NodePort, and LoadBalancer
 ∟ 📂 ConfigMaps and Secrets
 ∟ 📂 Probes including liveness, readiness, and startup
 ∟ 📂 kubectl contexts, namespaces, logs, and describe

∟ 📂 Phase 4 (Weeks 13–16) Kubernetes Networking
 ∟ 📂 CNI basics including how pods get IPs
 ∟ 📂 Ingress controllers NGINX, ALB, and Gateway API
 ∟ 📂 DNS inside clusters using CoreDNS
 ∟ 📂 NetworkPolicies to isolate traffic the DevOps way
 ∟ 📂 Troubleshoot networking using exec, curl, and logs

∟ 📂 Phase 5 (Weeks 17–22) Kubernetes Storage
 ∟ 📂 PersistentVolume and PersistentVolumeClaim
 ∟ 📂 StorageClasses with dynamic provisioning
 ∟ 📂 CSI drivers such as EBS, Diskfile, and AzureDisk
 ∟ 📂 StatefulSets and workload identity
 ∟ 📂 Backup and restore strategies

∟ 📂 Phase 6 (Weeks 23–28) Kubernetes Scaling
 ∟ 📂 HPA using CPU, memory, and custom metrics
 ∟ 📂 VPA and when to use it
 ∟ 📂 Cluster Autoscaler basics for node provisioning
 ∟ 📂 PodDisruptionBudgets for graceful scaling
 ∟ 📂 Karpenter for autoscaling with the right instance types

∟ 📂 Phase 7 (Weeks 29–34) Kubernetes Security
 ∟ 📂 RBAC with clean role and rolebinding practices
 ∟ 📂 Image scanning and SBOM basics
 ∟ 📂 NetworkPolicies with least privilege thinking
 ∟ 📂 Secrets management using KMS, SealedSecrets, and External Secrets

∟ 📂 Phase 8 (Weeks 35–40) GitOps and IaC for Kubernetes
 ∟ 📂 Kustomize overlays and env specific patches
 ∟ 📂 Helm charts values, templates, and packaging
 ∟ 📂 Terraform for provisioning EKS, AKS, and GKE clusters
 ∟ 📂 ArgoCD for sync, health checks, rollbacks, and drift detection

∟ 📂 Phase 9 (Weeks 41–46) Kubernetes Observability
 ∟ 📂 Metrics using Prometheus, Grafana, and exporters
 ∟ 📂 Alerts for errors, crashes, and SLO based thresholds
 ∟ 📂 Dashboards for deployment health, latency, and saturation

∟ 📂 Phase 10 (Weeks 47–52) Real Kubernetes Projects
 ∟ 📂 Deploy a production grade microservice stack
 ∟ 📂 Add autoscaling using HPA, Karpenter, and PDBs
 ∟ 📂 Add observability with logs, metrics, alerts, and dashboards
 ∟ 📂 Secure workloads with RBAC, PSP alternatives, and policies
 ∟ 📂 Document everything on GitHub and LinkedIn
