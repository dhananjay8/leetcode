# Company / Role-Specific Interview Prep

Deep-dive prep packs for specific companies, roles, or named systems — grounded where possible in public sources, with inferences clearly labeled. Each folder is self-contained: a README entry point, Mermaid diagrams, an interview Q&A bank, and (where applicable) panel cross-questions + behavioral prep.

| Folder | Target | Format |
|---|---|---|
| [`Cloud-Data-Hub/`](./Cloud-Data-Hub/README.md) | BMW TechWorks — Datahub Architect/Tech Lead (AWS & Full-Stack TypeScript) | JD-driven role prep: platform architecture (sourced), role-stack Q&A, 90-day plan, panel cross-questions |
| [`FortiRecon/`](./FortiRecon/README.md) | Fortinet-style Director system-design round (EASM/DRP platform) | From-scratch system design: requirements → architecture → deep dives → follow-up drill-down |

## How to Use

1. Start with each folder's `README.md` for the scope/framing.
2. Use `diagrams.md` to rehearse drawing the architecture from memory.
3. Drill `interview-qa.md` / `follow-ups.md` until you can answer without re-reading.
4. For role-based packs (not pure system-design), use `panel-questions.md` to prep both your own cross-questions and likely behavioral prompts.
