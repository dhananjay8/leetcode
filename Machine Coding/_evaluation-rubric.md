# Machine Coding Evaluation Rubric

Use this after each implementation to score quality and interview readiness.

## 1) MVP Completion (0-10)
- Core requirements implemented
- Basic happy path works

## 2) Code Structure (0-10)
- Clean component/module boundaries
- Readable naming and organization

## 3) State Management (0-10)
- Correct data flow
- Minimal unnecessary re-renders

## 4) Edge Cases (0-10)
- Empty states handled
- Invalid input handling
- Error states covered

## 5) Performance (0-10)
- Memoization where justified
- Efficient rendering for larger datasets

## 6) UX & Accessibility (0-10)
- Keyboard interactions
- Clear feedback/loading/error states
- Basic semantic/accessibility considerations

## 7) Communication (0-10)
- Clarified requirements before coding
- Explained tradeoffs and next improvements
