# 12-Week Interview Preparation Roadmap

This roadmap is optimized for product-based company interviews (SDE-1/SDE-2 style).

## How to execute each week
- **Weekdays:** 2 DSA problems/day (1 medium + 1 pattern-focused review)
- **Weekend:** 1 system design case study + 1 machine coding prompt
- **Daily revision:** 20–30 minutes from `DSA/cheat-sheet.md`
- **Tracking:** Maintain a mistake log (pattern, bug type, fix)

---

## Problem selection rule
- 60% medium, 20% easy, 20% hard
- Re-solve failed questions after 3, 7, and 21 days
- Prefer pattern batches over random browsing

## Interview week checklist
- Revise complexity templates and edge-case checklist
- Rehearse problem explanation in 2 minutes
- Practice writing bug-free code without autocomplete
- Keep backup examples for DB indexing, caching, and API design tradeoffs
