## How to Use During Prep

- Pick one local design note and one external read on the same topic.
- Summarize tradeoffs in your own words: consistency, latency, scale, cost.
- Rehearse a 45-minute whiteboard flow: requirements → API → data model → architecture → bottlenecks.
