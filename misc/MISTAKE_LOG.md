# Mistake Log

Capture mistakes with root cause and correction plan.

## Entry Template

| Date | Problem | Topic | Mistake Type | Root Cause | Correct Fix | Revisit On |
|---|---|---|---|---|---|---|
| YYYY-MM-DD | Problem name / link | e.g. Sliding Window | Off-by-one / wrong DS / bad complexity | What went wrong | How to solve correctly | +3d / +7d / +21d |

## Mistake Type Suggestions
- Pattern misidentification
- Edge case missed
- Off-by-one/index bug
- Wrong data structure
- Complexity too high
- Premature optimization
- Incomplete test cases

## Rules
- Add an entry the same day.
- Re-solve failed problems at 3, 7, and 21 days.
- If same mistake repeats 3+ times, create a dedicated revision note.
