# Solutions Directory Guide

Language-first and difficulty-first organization for coding problem solutions.

## Structure
- `easy/` -> mostly foundational problems
- `medium/` -> core interview problems (largest set)
- `hard/` -> advanced interview and edge-case intensive problems
- `misc/` -> grouped patterns and curated frequently-asked sets

## Naming Convention
- Prefer kebab-case with clear problem title identity.
- Keep one canonical file per problem per language unless showcasing a different approach.

## Study Strategy
- Start from pattern sections listed in root `README.md`.
- For each solved problem, track:
  - brute force idea
  - optimized approach
  - complexity
  - one bug you encountered

## Language Use
- Use the language expected in your interview loop.
- Re-solve at least 30-40 key medium problems in your primary language before interviews.
